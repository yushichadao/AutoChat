微信侧的本地 AI 助手

把本机登录的微信账号接到 OpenAI 兼容模型上。它只做一件事：收到微信消息 → 按策略交给模型 → 把回复发回微信。所有行为发生在你自己的账号里，模型可以跑在本机，也可以接云端。

核心能力

它帮你做什么

🤖

本地 AI 自动回复

接 OpenAI 兼容模型，本地或云端都行。群聊 / 私聊分别施策，支持触发前缀、@ 认可、人设与上下文记忆。

🛡️

总闸随时暂停

一行命令 autochat pause 立刻停掉自动回复（仍接收、仍记录），resume 恢复。自动化最怕停不下来，所以它最好找。

🧩

零运行时依赖

纯 Node.js ESM，无构建步骤、无 TypeScript、无框架。克隆即跑，npm test 108 项测试全绿。

🖥️

图形化配置器

不懂命令行也能用：autochat gui 打开网页配置模型、会话、护栏，安装 / 卸载、状态一目了然。

🔌

本机 hook 注入

通过第三方 hook DLL 读写本机微信进程收发消息。DLL 由你自行获取，本项目不分发任何第三方二进制。

⚖️

内置合规护栏

webhook 鉴权、自身消息过滤、限流、并发上限、否定语义拒绝——挡住技术事故，并明确合法使用边界。

快速开始

3 步跑起来

① 准备：小号方案

建议用一个小号 / 备用号接收消息，避免机器人把自己的回复当成别人的提问而自问自答。锁住微信版本，准备 hook DLL（见仓库说明）。

② 配置模型

推荐本机模型（Ollama / LM Studio）以保护隐私；也可接云端 OpenAI 兼容服务。

autochat setup        # 向导：选模型、填密钥、试连
# 或图形界面
autochat gui

③ 启动与体检

启动服务，用 doctor 按提示把 hook DLL 就位。

autochat start        # 前台启动服务
autochat doctor       # 环境体检：为什么机器人不理我
autochat status       # 状态总览（服务 / 总闸 / 配置 / 上下文）

完整文档见 README。不需要 DLL 与 API Key 也能 npm run demo 跑通全链路。

平台与风险

使用前须知

🪟 仅支持 Windows

hook DLL 注入依赖 Windows 微信客户端，macOS / Linux 无法运行核心收发能力。

⚠️ 账号封禁风险

个人号自动化违反《微信个人账号使用规范》，频繁使用可能被限制功能或封号。建议小号、控频、勿群发。
