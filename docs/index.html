微信侧的本地 AI 助手

把本机登录的微信账号接到 OpenAI 兼容模型上。收到消息 → 按策略交给模型 → 把回复发回微信。所有行为发生在你自己的账号里，模型可以跑在本机，也可以接云端。

核心能力

它能帮你做什么

本地 AI 自动回复

接 OpenAI 兼容模型，本地或云端都行。群聊 / 私聊分别施策，支持触发前缀、@ 认可、人设与上下文记忆。

按账号隔离身份

同一台电脑先后登多号，各用各的人设与记忆，绝不串台——"前世记忆"被彻底切断。

一键暂停自动回复

一行命令 autochat pause 立刻停掉自动回复（仍接收、仍记录），resume 恢复。自动化最怕停不下来，所以它最好找。

长消息等待提示

回复耗时超过 2 秒，先发一条独立的「等待回复中…」，再发正式回复，体验更顺、不让人以为"卡了"。

零运行时依赖

纯 Node.js ESM，无构建步骤、无框架。克隆即跑，npm ci 基本是空操作。

图形化配置器

不懂命令行也能用：autochat gui 网页改模型、会话、护栏，一键锁版本、自动选 DLL。

本机 hook 注入

通过 hook DLL 读写本机微信进程收发消息。发布包随附维护者专为 AutoChat 自制、适配的 hook DLL，开箱即用。

内置合规护栏

webhook 鉴权、自身消息过滤、限流、并发上限、否定语义拒绝——挡住技术事故，并明确合法使用边界。

长期记忆摘要

autochat memory 把对话沉淀为持久、可跨会话、可导出、可清空的摘要，隔天仍记得偏好与约定。

它是怎么工作的

一条消息的旅程

不连任何外部平台，不跨平台转发，不做群发。所有判定与落盘都在你本机。

1

收消息

hook DLL 读写本机微信，数据库轮询 / 注入拿到新消息。

2

策略判定

是否监听该会话、群聊策略、触发前缀、@ 认可、自身消息过滤。

3

调模型

本地或云端 OpenAI 兼容模型，按账号隔离人设与记忆。

4

回微信

清洗后发回，长消息先发"等待回复中…"，再发正式回复。

两个入口能力对等：命令行 autochat 与图形化配置器 autochat gui 共享同一套任务逻辑。它还是 DeepSeek Harness（dsh）插件，在对话里即可查体检、启停服务、暂停回复。

快速开始

两分钟跑起来

方式 A · 便携版（小白推荐）

无需安装 Node。下载压缩包 → 解压 → 双击 AutoChat.bat 启动；想后台常驻用 AutoChat-后台.vbs。初始化向导会带你锁版本、配模型、设小号。

↓ 下载压缩包（Windows）

方式 B · 源码（开发者）

git clone https://github.com/yushichadao/AutoChat.git
cd AutoChat && npm ci
npm run doctor      # 环境体检
npm run setup       # 向导：锁版本→配模型→设小号
npm start           # 启动（需管理员加 --elevate / 后台 --background）

验证：手机用另一个号给电脑上的小号发"你好"，几秒内应收到回复。建议用小号接收，避免 AutoChat 把自己的回复当提问而自问自答。
